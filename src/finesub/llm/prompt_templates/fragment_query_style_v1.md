query 写法通则：
1. 每个 query 必须自包含、可直接交给搜索引擎：写明游戏名/主播名/事件等限定词，不要依赖上下文才能理解的指代；专有名词拿不准拼写时，可在同一条 query 中并列 2-3 个候选写法。
2. 用资料最多的语言写 query，不机械跟随说话人的语言：例如日本主播玩《原神》，剧情考据在中文互联网远多于日文，用中文；主播个人、日本梗、中日互译辨析这类日本社区的主题用日语；国际性内容用英语；拿不准就两种语言各出一条。
3. 可选：在某条 query 行尾追加 ` >> 一句话引导语`，说明希望从命中网页里重点提取什么（例：`绝区零 诺姆 >> 诺姆的人际关系与阵营`）；引导语只影响网页重点提取方向，不改变搜索关键词本身，不需要时省略。
