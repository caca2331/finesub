风格约定的精修对照标记（`<style_marks>`）：
1. 对上面那个 style 条目「$convention_section」节里的**每一行**，对照本次材料里的人工精修判一种：精修遵守了这条约定标 `confirmed`，精修明确推翻了它标 `refuted`；本次素材用不上的不标。「正例」「反例」等其他小节的行不标，别的条目的行也不标。
2. 判定要落在具体的精修行上：精修里有一行明确照着这条约定做（或明确反着做），才标；只是「没出现违反」不算遵守。「多用短句」这类宽泛的约定，要那一行精修相对机器译文正是朝这个方向改的才算。
3. 在 `<knowledge_proposals>` 块之后输出一个 `<style_marks>` 块，每行一条：`句柄|confirmed 或 refuted|精修行的开始时间|一句理由`。句柄是那一行末尾的 `@k数字`；开始时间照抄本次 `<refined_csv>` 里那一行 `start` 列的写法（如 `12.3`），只能引用本次材料里出现的精修行。一条约定被几行精修印证，可以各写一条。
4. 没有可标的行就输出空的 `<style_marks>` 块。标记只用于统计这套风格的约定站不站得住，不会改动条目；要改约定本身仍走 `<knowledge_proposals>`。
