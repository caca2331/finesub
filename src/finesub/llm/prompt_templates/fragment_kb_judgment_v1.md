知识库判断标准（修复 / 校验 / 共享审核 / 材料吸收共用）：
0. 收录标准：这个知识库只为两件事服务——**让 ASR 听对**（源语言表层、读音、易错写法）与
   **让字幕写对**（中文定名、别名、语体/自称这类直接决定译文怎么落笔的）。两者都不服务的
   信息不收，无论多有趣：它会过期、会稀释注入面，还会把模型的注意力从该记的东西上引开。
   preset 在各节注释里建议的标记就是这条标准的具体化，按它走即可。
   ⚠ **有没有参照物决定你能写多硬**，看的是**手上这份材料**，不是任务的名字。任务后的知识
   更新有那一次的 ASR 文本与精修对照；一份材料里若同时带着「机器听成/译成什么」与「正确的
   是什么」（例如旧台账那种 `原文片段 + 正确译文 + 说明`），它同样是参照物，据此写
   「误听: xxx」是有据的。**材料里没有 ASR 文本时**——那就只写表层、定名与别名，
   **不要凭空断言某个词会被听成什么**，误听留给有对照物的那一轮去记。
1. 行的归属：一行属于哪一节由内容决定，**节的准入以条目预览里每节的「行式」说明为准**
   （那是 preset 生成的，不同类别的条目节名并不相同——别拿另一类条目的节名去套）。
   收术语行的小节里，术语行固定四列 `源语言|中文定名|别名|一句话描述`（无别名时第三列
   留空，多个别名用顿号分隔；描述在最后一列，可含竖线）；只收自由句的小节里竖线只是普通
   字符。主播条目的频道相关名词（粉丝统称、吉祥物/道具名、固定环节名、自称/他称）一律是
   `频道用语` 的术语行。行首可选 `[标记]`，同一节内标记唯一。
2. 同一实体判定：表面形经规范化（全半角/大小写/繁简/假名折叠）相同即同一实体；写法差异不构成新实体。
   拿不准时倾向「不同」——错误合并比重复更难恢复。
3. 描述纪律：术语描述是**身份稳定的一句话**；版本性叙事（皮肤、活动、单集剧情）直接省略——它会随版本过期，条目要长期有效。
   「误听: xxx」是录入语法，写入后会转为结构化数据并从描述中消失。
4. 标记名向已有的靠拢（本名/别名/人设/外观/语体/音色/自称/出道/生日…），同概念不要换名散写；
   没有内容的标记**不写**（稀疏=缺席）。你在完整预览里看到的空槽是清单，不是待办——
   没有证据就留空。
5. 证据纪律：你的结论不是证据。可核实的外部出处只有**你亲自打开核实过的 URL**；查不到就如实标注，
   不要用推测填充。
