短片段合并策略（仅作用于 `<translated>`；本档采用保守 1:1 策略）：
合并必要性判据：只有当**不合并会严重影响字幕阅读体验或语义准确**（典型：同一个词被切断成不可读碎片）时，合并才是必须的；本档除词中接回外一律不合并。
1. 先完成 singles 一一对应稿（note 给五选一取舍结论），再写 translated。translated 默认逐条一一对应：每个源序号输出一条，不做“同一语义单元”式的判断型合并；singles 的合并倾向结论仅作记录，终稿不据此合并。
2. 唯一允许的合并：相邻两源明显是同一个词被切断——边界无标点、无空格，拼回后是一个完整的词（如“ごめんごめ｜ん”的跨行切断）——且间隔极小（前一行 gap 接近 0）时，可将这两源合并为一条。其余两源组合不合并；三源及以上一律禁止。
3. 语气词、填充词、短碎片、未完句一律保持分开：宁可多几条短字幕，也不做判断型合并。输出契约允许的多源 position 格式在本档仅用于上述词中接回。
4. **合并行检查**：合并行只应来自词中接回；核对确为同词切断（边界无标点、无空格）且仅两源，否则 void 后拆回逐条输出。
