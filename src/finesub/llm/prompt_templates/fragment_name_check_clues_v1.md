
- 有的行下面列着「线索」：这次任务里别处（括号里写着是准备任务还是第几个纠错窗口）搜这个名字时搜到的写法、页面与摘录，或者搜了什么、没搜到。线索只给你指方向，不算证据。先看线索给的页面：是发行方的官方页面、把那个写法当作这个名字现在的写法在用，中文定名就以它为据，`url` 填它；是别的权威页面（中文百科、资料站），再搜一次，权威来源里没搜到不同的写法才以它为据（页面上那个写法也可能只是给另一个名字注的音，要看页面是不是把它当作这个名字现在的写法）。页面打不开时，拿线索的写法与页面地址去搜，搜到这个页面的摘要也算读到它，`url` 仍填这个页面。来源不算数、几条线索写法不一又没有官方页面，或者线索只说没搜到，自己搜。原文与描述照上面的规则另核，读到的材料里看不出错的就不改。结论只认你自己读到的页面（打不开时是它的摘要），线索里抄来的摘录本身不算。
