认人从点名开始：先认出本窗每条轨上实际开口的是谁（看称呼、自称、口癖、谁在回答谁），写成 `<translated>` 之前的 `<tracks>` 轨人表，再逐行写 `spk`。一条轨上看出两个以上的人时，轨号归这条轨的主人：本窗在这条轨上说得最多的那一位（通常也是画像例句像的那一位）；其余的人是另一条轨的主人就写那条轨，不是任何一条轨的主人就各用一个 `@` 标签，本窗这个人的每一行都写它。一个人占着几条轨时，他的几条轨都算对，他的行照抄各自的轨号。`spk` 写你认出的人，不是照抄 `track` 格子：台词显出这一行是别人时，就不照抄；看不出是别人的行，照抄现在的轨号。

`<tracks>` 轨人表：本窗 `spk` 要用到的每条轨、每个 `@` 标签各写一行 `轨号或标签 = 人名`（人名的写法同 `@` 标签，认不出写 `不明`）；画像里有、本窗没用到的轨不写，`?` 不进表。混在某条轨上、不是它主人的人，按他自己的轨或 `@` 标签在表里另占一行。

每个字幕行的说话人写进 `<translated>` 的 `spk` 列，只能是下面几种之一：
- 一条轨号：画像里列出的任意一条轨，或这一行 `track` 格子里出现的轨——如果有一条轨就是这一行的说话人，用它。现在的轨号是对的就照抄（`s5+s4` 行主轨 s5 是对的，写 `s5`）；
- `@新轨`：**新建一条轨**。只在你判断这一行的说话人**不是**画像里任何一条轨的主人时用（混进一条轨里的人不是任何一条轨的主人时，也算新人）。写法是 `@` 加一个标签：认得出是谁就写名字（「候选人物」里有的，照抄括号前的写法；名单里没有的，写台词里对他的叫法），
  认不出就写 `@甲`、`@乙` 这样的代号。同一个标签就是同一条新轨，本窗这个人的其他行也用同一个标签；
- `?`：证据不足（`??` 行定不了给哪条轨，也写 `?`）。这是正当答案，改错比不改代价大。
一行里有时混着两个人的话（插话、附和、抢话）：`spk` 写这一行**大部分是谁说的**。合并行只写一个 `spk`，它覆盖的每一行都是这个人；`discard` 行不写 `spk`。

改了轨的行——`spk` 写了 `track` 格子主轨以外的轨、给 `??` 行挂上轨、写 `@` 标签，或合并行盖住了挂在别的轨上的行——note 写一句短结论：是谁、凭什么（写法见下面的示例；这是凭据，不是推理过程）。说不出凭据，就是没有明确的理由改：照抄现在的轨号。写 `?` 不算改轨，不用写。

下面只示范 `spk`、note 与 `<tracks>` 的写法，轨号、人名与情形都是虚构的，与本窗无关（真实的窗里多数行是第一种）：
- `track` 是 `s1`，在回答上一行的提问，没有线索指向别人：`spk` 写 `s1`，note 不必写
- `track` 是 `s1`，在回答上一句对她的称呼，自称与 s2 的例句一致：`spk` 写 `s2`，note 写「在回答对她的称呼，自称与 s2 的例句一致」
- `track` 是 `s1`，被叫作花子的人在回答，她是候选人物里的山田花子，画像里没有一条轨是她：`spk` 写 `@山田花子`，note 写「被叫作花子的人在回答，画像里没有她的轨」
- 和花子对话的另一个人，画像里没有他的轨，认不出是谁：`spk` 写 `@甲`，note 写「和花子对话的另一个人，不是画像里任何一条轨的主人」

这几行对应的轨人表：
<tracks>
s1 = 佐藤一郎
s2 = 铃木美香
@山田花子 = 山田花子
@甲 = 不明
</tracks>
