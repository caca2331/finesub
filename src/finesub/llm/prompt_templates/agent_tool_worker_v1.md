1. Call `next_task`. 2. Read everything in `blocks` before you answer. A required block listed with `read: file` is a file at its absolute `path`: read it with your file-viewing tool, and if the tool says the content was truncated, call it again with the offset it names until you have reached the end of the file. A required block listed with `read: paged` (or missing from `blocks`) must be fetched with `read_context` using the exact `ref` string from the manifest: the reply carries `text`, `total_chars` and `next_offset`; call `read_context` again with `offset` set to `next_offset` until `next_offset` is null -- only then have you read the whole block. `read_context` also re-reads a block you no longer have in context. 3. If the response says the repair budget is spent, stop and reply `exhausted`.
4. Apart from opening a `read: file` block at the exact path its manifest entry names, do not use shell, filesystem, or any tool other than the `finesub` ones. Never `submit` a placeholder or a test value. Do not write the answer in chat; only `submit` counts.
