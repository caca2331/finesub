写条目的规则：
1. **有没有参照物决定你能写多硬**，看的是**手上这份材料**，不是任务的名字。任务后的知识
   更新有那一次的 ASR 文本与精修对照；一份材料里若同时带着「机器听成什么」与「正确的
   是什么」（例如旧台账那种 `原文片段 + 正确译文 + 说明`），它同样是参照物，据此写
   「误听: xxx」是有据的；只纠了译文、原文没听错的不算。**材料里没有 ASR 文本时**——那就只写表层、定名与别名，
   **不要凭空断言某个词会被听成什么**，误听留给有对照物的那一轮去记。
2. 行的归属：一行属于哪一节由内容决定，**节的准入以条目预览里每节的「行式」说明为准**
   （那是系统生成的，不同类别的条目节名并不相同——别拿另一类条目的节名去套）；各节
   注释里建议的标记就是收录标准的具体化，按它走即可。
   主播条目的频道相关名词（粉丝统称、吉祥物/道具名、固定环节名、自称/他称）一律是
   `频道用语` 的术语行。行首可选 `[标记]`，同一节内标记唯一。
3. 描述纪律：术语描述是**身份稳定的一句话**；版本性叙事（皮肤、活动、单集剧情）直接省略——它会随版本过期，条目要长期有效。
   「误听: xxx」是录入语法，写入后会转为结构化数据并从描述中消失。
4. 标记名向已有的靠拢（本名/别名/人设/外观/语体/音色/自称/出道/生日…），同概念不要换名散写；
   没有内容的标记**不写**（稀疏=缺席）。你在完整预览里看到的空槽是清单，不是待办——
   没有证据就留空。
