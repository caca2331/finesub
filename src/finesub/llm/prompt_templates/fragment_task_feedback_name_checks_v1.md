`name_checks`：素材里说到的、知识库里 `（未核）` 与 `（未核，查不到）` 行的名字在搜索里的中文写法，为核对 `（未核）` 行专门发的搜索与别的搜索里碰到的都算，每搜到一种中文写法记一条，与库里一样的也记（核查从它出发，往往一读页面就能印证）；专门发的那次没搜到中文写法，也记一条。素材里说到的、没有这两种标记的术语行，只在搜索里碰到与它的定名、别名都不同（繁简、全角半角之差不算）、有来源的中文写法时记一条（定下来的定名也可能错），与定名一样的不记，也不为它专门去搜。`source` 照抄那一行第一列的原文，`kb_zh` 照抄它的定名，`found` 写搜到的中文写法，`url` 写写着这个写法的页面地址，`quote` 抄那条搜索结果里写着它的一两句原文，`query` 写你搜的是什么；没搜到时 `found`、`url`、`quote` 留空。这两种行的定名与搜索结果不一致的，只记在这里，不再当作冲突或疑点写进别处；照哪个写法写，仍按对这两种行的规则。没有标记的行仍照知识库写，分歧照旧按别处对冲突的规则记下，这里的一条是另记的。
