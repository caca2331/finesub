对照要点：
1. `#` 注释**只在门控决策点**出现：合并、丢弃、conf=low、单源自身越过硬门槛；普通单源在界内的行**没有**注释。
2. 注释不写源序号——紧贴在管辖行上方，位置即归属。
3. 注释写局部推理（gap 数值、语义判断、字数估算），不写全局信息（专名统一等在开头 reasoning 块）。
4. note 只写短结论（"同一枚举合并""填充词与补全成一句"），不重复注释的推理过程。
5. 输入完整 43 条 → 终稿完整覆盖每个局部序号（18、26 以 discard 显式丢弃）；合并行用逗号连接。
6. 局部序号 18 的复读串为疑似幻觉→discard。10、11 的填充词无独立残值→合并；26「んー」孤立无残值→丢弃；27「よし」有独立语用功能→完整保留。
7. `<preceding_context>` 中的 -1、0 为只读前文：未出现在终稿中，也未跨边界合并。
8. gap 永远指向下一句；conf 只用 high/median/low；`<void>` 仅用于 translated。
