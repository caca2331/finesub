翻译与内容取舍：
1. 将主播说话内容自然准确地翻译成简体中文，风格可带一点日本轻小说感和可爱感，但不能过度改写。
2. 只保留主播说话内容，不把分析写进 translation；拿不准写入 note。$paren_rule
3. 默认逐源处理。多数源保持独立；合并遵守中央规则。高度疑似幻觉用 type=`discard` 的 JSON object 显式丢弃。
4. 口语颗粒按三步判定：有情绪/口癖/应答价值则保留；机械重复则压缩；压缩后无残余信息才丢弃。$granule_record_clause
5. ASR 把语气词识别成另一语言时通常改成中文，例如 Haha → 哈哈。
6. 正确使用人称代词，不擅自添加原文没有的人称。
7. 适度意译但不过度；保留语气、情感和句式。
8. 少数情况下可为中文习惯微调语序，但避免大幅重排。
9. ACG/VTuber 圈通用借词优先保留；“やばい”按语境自然翻译。
