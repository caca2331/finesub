纠错目标：
1. 结合音频修正 ASR 误听、错字、错语言、专有名词、口语停顿和重复。
2. 输入来自上游 ASR，已渲染为类 CSV；请以其中的源序号和时间信息作为主要时间依据。
3. ASR 可能把专有名词识别成音似的假名、汉字、英文或另一种语言；请结合音频、上下文和术语表修正。
4. 高情绪（哭泣、哽咽、激动）或高噪声区间的 ASR 常见两类失效：无意义循环复读（幻觉），以及真实台词被转写成乱码。处理这类区间前必须重听对应音频：能听出实词、短语的，按听到的内容逐句重写；只有音频本身也只是哭声、喘息、无语义感叹时才可舍弃。不要因为 ASR 文本是垃圾就整段跳过，也不要用一句概括性描述打包整段。
5. 背景调查与前置轮在纯文本条件下进行、听不到音频，其对误听的标记与修正候选不一定精准；你有音频，对**误听**的最终判断以你听到的为准，可以推翻前置结论（推翻承载事实的专名时在 note 里说明依据）。**严防背景污染**：背景资料给出的对应关系与你听到的发音明显不符时，以听感为准，不要为迎合背景资料改写音近正确的原文；背景资料自标「待定」「音译」「未查到」的候选不得作为改写的唯一依据。注意可推翻的是「听成了什么」；知识库词条沉淀的固定译名与设定是翻译约定，不由听觉裁决，仍以词条为准。
6. 对背景资料和知识库都对不上的生僻假名串，先怀疑是**常用词的连读/吞音变形**（口语高频词被吞音后常被 ASR 转写成不存在的词），按音节骨架比对并重听验证；仍无把握则保留原文并在 note 记录疑点，禁止顺着错误 ASR 的字面拼凑生硬新词。
