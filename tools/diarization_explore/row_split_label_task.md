# 任务：给一批「一句日语字幕被切成两行」的样本逐条打标签

以本任务的要求为准（包括输出格式与语言）。只读下面列出的文件，不要跑命令、不要联网。

## 背景

一条字幕管线把日语语音转成字幕行。有时一个规则会把**同一个人说的一行**从中间某处切成两行（左半、右半）。之后有一个纠错步骤（一个语言模型），
它会读相邻的字幕行，把属于同一个语义单元、被切开的相邻行合并回一行；但如果两行各自是独立完整的话，它不会合并。

我们想知道：每一处切分，纠错之后会被并回去（危害小），还是会留成两行（危害大，因为右半行还会被挂到另一个说话人名下）。

## 材料

文件（JSON Lines，每行一条）：`$FILES`

每条的字段：`id`（原样抄回）、`prev`（前一行字幕，可能为空）、`left`（被切的这一行的左半）、`right`（右半）、`next`（后一行字幕）。
文字是语音识别的结果，可能有错字。**`left` 与 `right` 都是同一个人说的**，这一点已经确定，不用判断。

## 标签（每条选一个）

- `MERGE`：左右两半是一句话或一个语义单元被切开：切在词中间、短语或从句中间，或者右半是左半的延续（以助词、助动词开头，或补完左半的句子）。
  纠错会把它们并回一行。
- `KEEP`：左右两半各自是独立完整的话（各是完整的句子、问句、感叹或称呼加完整的句子），分成两行读起来自然，纠错不会合并。
- `FILLER`：其中一半只有语气词、感叹词、附和（如「うーん」「えー」「よし」「ねえ」「はい」「いやー」），另一半是正常的话。
- `UNSURE`：真的判断不了。只在确实无法判断时用。

`prev` / `next` 只用来帮助理解语境，标签只针对 `left` 与 `right` 之间这一处切分。

## 产出

在你的当前工作目录下写一个文件 `labels.jsonl`，每条输入对应一行、顺序与输入相同、条数相同：

```
{"id": "<原样抄回的 id>", "label": "MERGE|KEEP|FILLER|UNSURE"}
```

不要加别的字段，不要漏条。写完后，在回答里只报告：总条数、各标签的条数、你觉得最难判的 3 条（id + 一句理由）。
