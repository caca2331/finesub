# Qwen3-ASR / Qwen3-ForcedAligner 探索：结论

分支 `explore/qwen3-asr` · RTX 5060 Ti 16 GB · 日语 VTuber 直播 11 个 clip
（8 个 `BV*` + `yingtao` / `yui` / `kaguya60`）。

本文只保留**结论与判据**。推理过程、被推翻的中间结论、机械指标的调参史都已删除
（在 git 历史里）。方法与规范见 `docs/segmentation-gold.md`，迁移设计见
`docs/segment_split.md` 末节。

---

## 0. 先读这一节：什么样的对比才算数

这个探索里**每一个被推翻的结论，根因都是对比不干净**，不是数据不够。四条纪律：

1. **进程内重算，别信磁盘产物。** 曾用过期 `*-QS/WS.json`（含已删除字段）出过一整张错表。
2. **锚定要选对。** 时间锚定给"提供底本的那一臂"送分（它零误差命中，别人交 τ 税）；
   `snap_cues_to_speech` 能让**逐词完全相同**的分段从 95.8% 掉到 75.0%。
   **同文本的臂一律用 `score --by-index`**（词序号精确匹配，时间不参与）。
   跨 ASR 文本的臂只有 75–92% 字符能映上，绝对读数按不可判定处理。
3. **一次只动一个变量。** 拿 `qwen_split` 去代表"全局 DP"曾得出两个错误结论——它同时改了
   作用域、刀钱、gap 折扣、6 个新增项和后处理。正确做法是调用**生产自己的函数**、
   只换那一个变量（`tools/qwen3_explore/scope_control.py` 的做法）。
4. **基线要对。** 8 个 `BV*` clip 的存档产物 `splitted_before` 全为 0、metadata 只有
   `asr_align`——**`split_segments` 从未在它们上面跑过**（那是实验中间产物，不是生产成品）。
   基线必须取「重跑 `split_segments`」。

补一条尺子本身的教训：批 3 标注出现过 `ok` 塌缩（并入 `never`）。修复后重跑全部结论，
**各臂违反数等量下降、臂间差值一个没变**。**这类标注偏差对「比较」是中性的**——
可被差分消掉的系统偏差，和不可消的噪声，危害完全不同。

## 2. 金标准怎么用（规范见 `docs/segmentation-gold.md`）

- 两个指标：**必切召回**（真正的率）、**禁切违反**（报绝对数 + 每百条 cue，不报百分比——
  分母是候选规则碰巧捞出多少个禁切位，不是自然总体）。**零 `must` 窗口不能并进汇总。**
- 拟合集 = 批 1（3 窗 61 `must`），留出 = 批 2+3（11 窗 163 `must`）。
- **逐窗口胜负比汇总差值更稳**：「14 窗无一变差」不依赖标签绝对正确，只需标注自洽。

## 3. 目标 2：分句器

### 3.1 生产端参数没有空间，但 `no_gap_penalty` 的**条件**是错的

分句器只造窗内 **32/563 = 5.7%** 的刀（其余是 ASR 分段边界），这是任何参数改动的结构上限。
15 组单参数扰动最好的两个是 `b=2.0`（留出 +2 `must` / +5 违反）、`no_gap_penalty=0.5`
（+1 / −1），全在 ±1–2 的噪声量级。

真正的问题在判据：`interval_gap_between` 首行 `if j <= i: return 0.0`——**两个词只要 anchor
到同一个 VAD 区间，`g` 恒为 0**，不论实际隔了 2 秒还是 0 毫秒（能量 VAD 会把没跌破阈值的
停顿并进同一区间）。于是所有区间内边界代价都是 `t + base + no_gap_penalty = t + 2.0`，
而 `t_score` 只有六个离散值。全测试床段内 25114 个边界里 `g=0` 占 **24588（97.9%）**，
gold 窗内 183 个 ASR 边界（含 42 个 `must`）共用这一个并列类。

而对齐器的**词级**时间戳在其中一部分位置是报了停顿的（`must` 中位 +0.195 s vs 推定禁切
+0.000 s，仅 9% 超 0.05 s）。只要有词停就免收该罚则，纯逐段路径上即可得
**+1 `must` / −1 违反，14 窗无一变差**。

### 3.2 最终设计：`g<=0` 分支换成一条连续项 + 全局 DP + 分段奖励

    g <= 0 时：  score = max(-1, (pause == 0) * penalty - pause**2)
                 b     = a * (t + score) + base
    参数：       whisper_segment_bonus = 4.5,  non_vad_gap_penalty = 1.0

`pause == 0` 时精确退化成现状（`t + 1 + base`），是**推广不是替换**。收益（留出 163 `must`，
基线 = 重跑 `split_segments` 的 155/163 · 412 刀 · 132 违）：

| | 必切召回 | 刀 | 违反 | 逐窗 `must` 好/平/坏 | 逐窗 违反 好/平/坏 |
| --- | --- | --- | --- | --- | --- |
| **b=4.5 / penalty=1** | **156/163** | **403** | **122** | **1/13/0** | **6/8/0** |

`b` 的严格区间 **4.5–7**（≤4 起有窗口变差，≥7 退回基线）；`penalty` 平台 **0.75–1.0**
（≥1.5 起毁 `must`，3.0 时拟合集 58→48）。**`penalty=1` 恰在平台边缘——生产原有的
`no_gap_penalty=1.0` 数值本身是对的，错的是它的条件。**

**收益的分解**（这决定值不值得改作用域）：

    免罚单独（b=7，此时全局已等价逐段）  +1 must,  −1 违反   ← 几行判据修改
    纯全局 DP + bonus（b=4.5）          −1 must, −11 违反   ← 减过切必付漏切
    两者合起来（b=4.5）                 +1 must, −10 违反   ← 互补，免罚补掉了漏切

纯粹的全局 DP + bonus **没有免费区间**：`b=5.5–6` 严格不劣但只减 2–4 刀 / 1–2 违反；
往下 4.5/5 能减 8–11 违反，代价是各有 1 窗掉 `must`。**架构改动本身只值 −2 违反，
其余靠免罚——而免罚不需要全局 DP。**

二次项在本批 gold 上不产生差异（`b=4.5` 二次式 403/122 vs 纯免罚 401/122），因为
`g=0` 桶只含短停顿（停顿一长 VAD 就切开了）：全床段内该桶有词停的仅 438 个（1.8%），
词停中位 0.140 s、p90 0.320 s。**采用它的理由是覆盖桶展示不了的失效模式**——
人声分离残留抬高底噪、能量 VAD 漏语音的素材（`yingtao`，非语音 −48.7 dB），此时
0.5–0.9 s 的词停与 `g=0` 并存。不更差 + 覆盖已知失效模式 + 退化性好。

**已于 2026-07-29 迁入生产**（验收全部通过，实跑复现本节数字：留出 156/163 · 403 刀 ·
122 违反）。迁移设计、复杂度界（可证 `d ≤ 20 s`）、tag 反转、幂等性前提与验收实跑结果：见
`docs/segment_split.md`「全局 DP + ASR 分段奖励」节。**本目录的原型脚本
（`wordgap_ladder.py` 等）未随之更新，对当前 `SplitParams` 已不可运行。**

### 3.3 剩下的漏切调参够不着

留出集上生产漏掉的 8 个 `must` 里，一半在 `BV1kYLR6AEXv`——主播朗读弹幕/评论、系统事件
插入、引用他人话语，即**发话身份切换**。该窗生产命中 7/11，**整个参数空间最好 8**，
其中 2 个零声学信号。切在这里需要知道「谁在说话」，而朗读时声学上仍是同一个人、
diarization 也帮不上；这是话语层的引用关系。**这是 DP + 声学/词法特征的能力边界。**

## 4. 目标 3：Qwen ForcedAligner

### 4.1 对分割结果无可测影响（干净口径下重测）

同文本、同分词、同标点，只把词时间戳换成 Qwen 的（按字符偏移映回 whisper 分词）。
3 个有 gold 窗口的 clip、48 个 `must`：

| 臂 | 必切召回 | 刀 | 违反 |
| --- | --- | --- | --- |
| wt + 生产分句 | 85.4% (41/48) | 123 | 41 |
| **qwen + 生产分句** | **85.4% (41/48)** | **123** | **41** |
| ow + 生产分句 | 85.4% (41/48) | 125 | 43 |
| wt + 新设计 | 85.4% (41/48) | 123 | 42 |
| qwen + 新设计 | 85.4% (41/48) | 122 | 40 |
| ow + 新设计 | 83.3% (40/48) | 118 | 40 |

`ow` = openai-whisper 自带的 `word_timestamps`（第三对照，见 §4.2）。

**逐位相同**；刀集差异 ≤1 处（且那 1 处是 `never`）。**不需要按 Qwen 调参**：它的
特征提示的那个旋钮（最小停顿阈值，防 §4.3 的伪造停顿）在 0.05 无作用、在 0.1 反而掉 1 个
`must`。样本只有 3 窗 48 `must`，结论是「测不出差异」而非「已证相等」。

### 4.2 差异全部落在**显示时刻**上，且切点处比平均更差

切分**位置**相同，但同一刀的**时刻**并不一致（`Δt` = 左词 end 与右词 start 的中点之差）。

**第三对照给出了噪声地板**：`ow` = openai-whisper 自带的 `word_timestamps`，与生产用的
`whisper_timestamped`（efficient）是**同一思路的两个实现**（都是 cross-attention DTW，
同一个 large-v3-turbo）。`ow` 是重新解码、文本只有 0.888–0.947 相似度，所以三个配对**一律
限制到 `ow` 的字符对齐可信位置**（长匹配块内部、离两端 ≥5 字；1435/2536 词间位、63/123 刀）
——否则 `wt~qwen` 用 123 刀、`qwen~ow` 用 63 刀，两个数字不可比。

| 配对（同 63 刀） | 中位 | p90 | >0.3 s | >0.5 s | 最大 |
| --- | --- | --- | --- | --- | --- |
| **wt ~ ow（同方法地板）** | **0.015 s** | **0.076** | 4.8% | **0.0%** | 0.33 |
| wt ~ qwen | 0.040 s | 0.169 | 4.8% | 1.6% | 0.88 |
| qwen ~ ow | 0.046 s | 0.196 | 4.8% | 1.6% | 0.86 |

三点：

- **差异在典型幅度，不在尾部频率**：超 0.3 s 的比例三对完全相同（4.8% = 63 刀里 3 刀），
  但 Qwen 的中位是地板的 **2.7 倍**、p90 **2.2 倍**，超 0.5 s 的地板是 0% 而 Qwen 是 1.6%。
- **切点比平均更差**：全集上 `wt~qwen` 切点 14.6% 超 0.3 s vs 全部词间位 9.0%——刀落在
  停顿上，而停顿正是对齐器最不一致的地方。全集 123 刀 / 6 分钟里 18 处 `Δt>0.3 s`
  → **约 3 处/分钟**（旧版写「每分钟最多约 1 处」，是另一套口径，低估了 3 倍）。
- **那 63 个刀是偏容易的素材**（`ow` 文本对得上的地方正是声学上不难的地方），所以同底表里
  的绝对比例偏乐观；全集的 14.6% 才是真实世界估计，只是那部分没有地板可比。

**但这个「地板」只适用于段内。** 上表是**重定时之后**量的：donor 的时间按字符偏移映到
baseline 词流上，donor 自己的段结构与 baseline 不重合，段边界处取到的其实是 donor 的**段内**
时间。两边都跑原生、按位置类型分开看（`raw_edges.py`，两边都判为该类型才计入）：

| 位置 | n | wt(`refine=0`) vs ow | **wt(`refine=1.0`，生产值) vs ow** | `refine` 自己移动了多少 |
| --- | --- | --- | --- | --- |
| 段首词·头 | 214 | 0.360 s / 52.8%>0.3s | **0.180 s / 26.2%** | 0.340 s |
| 段尾词·尾 | 225 | 0.080 s / 27.1% | **0.020 s / 7.6%** | 0.140 s |
| 段内词 | 2081 | 0.020 s / 2.5% | 0.020 s / 2.2% | **0.000 s** |

- **两个实现只在段内与段尾一致**（0.020 s）；对「一个 segment 从哪里**开始**」始终分歧，
  即便带 `refine` 也是段内的 **9 倍**（谁把首词前的静音算进去）。
- **`refine_whisper_precision`（wt 自带、生产用 1.0）只动边界**：同一次解码下段内移动中位
  恰好 0.000 s，解码逐词不变；开着它段首分歧减半、段尾降到四分之一。
- **生产在 refine 之上的额外工程只动段尾**（中位 0.115 s，`extend_last_word_end_with_energy`
  按设计工作），段首 0.025 s、段内 0.010 s 几乎不动。**不是工程抹平了差距，是 `refine`。**

> **口径警告（这里错过三次）**：① `refine` 必须按生产设 1.0，关掉它等于关掉被测机制；
> ②「与生产一致」指**有效行为**——`asr_align` 名义上 `condition_on_previous_text=True`，
> 但它按 30 s VAD 分组解码、每次只有一个 whisper 窗口，有效等价于 `False`，照抄名义值整片跑
> 会把相似度从 0.88–0.98 打到 0.52–0.60；③ 两侧的「段首/段尾」必须**同时**成立才可比
> （生产的 segment 是 VAD 分组、原生的是解码器分段）。细节与复现见 `raw_edges_cmp.py` 文首。

所以 0.015 s 是「**段内**时间戳的同方法噪声地板」——`wt~qwen` 相对它的 2.7 倍仍成立，
但绝对值不能外推到切点时刻，切点落在段边界上，那里连两个 whisper 实现都差 0.180 s。

**段首的分布不是一个稳定偏移**（wt `refine=1.0` vs ow，n=214）：
`p25 0.100 / 中位 0.180 / p75 0.300 / p90 0.480 / p95 0.960 / p99 2.400 / 最大 5.70`，
**26% 超 0.3 s、7% 超 0.6 s**；方向上 173 晚 / 34 早（wt 系统性更晚），即系统偏置叠长尾，
不是对称噪声。段前静音长度**解释不了**它（r=0.23，分桶中位 0.08/0.18/0.30/0.18/0.18 不单调）；
只有极端尾部集中在长静音（>1.5 s 桶的 p90 为 1.360 s）——**长静音决定最坏情况，不决定典型情况**。

**「段中的切点」在本数据上几乎不存在**：分句器新造的刀只有 3/263（1.1%）。生产在每个 ASR
segment 边界都切，所以**刀的位置 ≈ 段边界**；段内 2080 个非切点虽只差 0.020 s，但那些位置
根本不会被切。**故切点的时间不确定性就是段首/段尾的不确定性——段尾 0.020 s（有共享偏差，
靠能量补齐纠正），段首 0.180 s 中位、26% 超 0.3 s，且全链路无人纠正。**

盲听 A/B（只取两者分歧处）**18:0 指向 wt**（13:0，p=0.00024；第二轮带标点词界 5:0，
两轮都破了混淆）——所以这 3 处/分钟的偏差方向上是 Qwen 更可能错。**但后果是短暂不同步、
不是文字出错**：cue 文本由词序号区间决定，时间戳不参与。

### 4.2b 本探索**未**验证的相邻主张（来源须标注）

以下三条被并进目标 3/4 的结论时常被当成本文测得，实际不是：

| 主张 | 来源 | 本探索的状态 |
| --- | --- | --- |
| faster-whisper 自带 word timestamp 的行为 | 使用者观察 | **未测**（未安装）；`ow` 同族可作旁证 |
| faster-whisper 极大提速 + 支持 batch | 使用者观察 | **未测**；本地 `ow`/`wt` 同速（共用 openai-whisper 解码器） |
| 更现代 ASR「更小/更快/幻觉更少」 | 模型卡 benchmark | 更小更快对 Qwen 本地复现；**幻觉已补测，见 §5.1——是失效模式不同，不是更少** |

**迁移性警告**：本探索里「benchmark 成立、本素材不成立」已出现两次——机械指标与人工 gold
在唯一干净的对比上**符号相反**；Qwen 自带标点实测扛着 21.6 个点，整体仍落后约 30 点。
日语 VTuber 直播（重叠 / 笑声 / BGM 残留 / 朗读弹幕）离模型卡评测集很远，**架构属性
（参数量、RTF）可直接采信，行为属性（错误率、幻觉率）建议在本素材上验过再写进结论**。

### 4.3 接入清单

- **单拍助词压成 0 ms** 是 80 ms 分辨率的地板（6–8.5%），**不是错误**，给下限时长即可；
  **整句被塞进小段**只在长窗口出现（逐段窗口 217 段 0 例）。
- **别直接用库里的 `_fix_timestamps`**：坏文本上把 14% 放大到 40%（长窗口下的线性插值
  正是句子级坍缩的成因）。
- **Qwen 会凭空造出停顿**：同一批词上非零词间停顿密度是 wt 的 4 倍（12.2% vs 3.0%），
  非零中位 0.240 vs 0.120 s。测量成立；由此提的修法被否掉了。
- **窗口长度别贪长**：整段单次解码会静默截断，要用长窗口先套覆盖率检查。Qwen 侧分词硬编码
  nagisa（日语）/ soynlp（韩语），其余按 CJK 逐字；**所有分支都丢标点**。

## 5. 目标 4：Qwen ASR 文本 + 全局分句

三条独立证据合起来，这条线可以结清，不必单独立项：

1. **已经量到**：词序号口径下 qwen 60.2%、whisper-split（同一个全局 DP、忽略分段信号）
   63.9%，差值落在跨文本映射噪声内；两者都比用上分段信号的 whisper-prod 低约 30 点。
2. **「按 qwen 调参」早就做完**：`bench.py --cv` 的交叉验证**只在 qwen 臂上跑**，
   现行 `qwen_split.Params()` 就是 qwen 选出来的。
3. **它的语言模型信号已榨干**：Qwen 自带标点而 whisper 基线基本不带，实测标点正扛着
   **21.6 个点**（取消标点折扣：60.2% → 38.6%），即便如此仍只到 60.2%。
   **whisper 的 segment 边界比标点多带 30 点的信息**——它是句子级切分假设，能抓到没有
   标点的话轮切换。

推论：若将来真要用 Qwen ASR，**别丢掉它的 `segments`**；能让它输出**句子级**分段才是补上
这 30 点的唯一路径。**注意这条否定理由只在「由 DP 分句」时成立——若改由 LLM 分句，
LLM 自己读文本判话轮，这 30 点不必再从 ASR 拿，该结论自动失效。**

ASR 文本本身三项追平基线、**不是升级**；救援阶梯可移植但要用重写版（照抄生产的渐进剥离会
退化到 RTF 3.0）。

### 5.1 「幻觉更少」实测：不是更少，是失效模式不同（3 clip / 13.5 min）

| 臂（均无工程，除注明） | 复读循环 | 静默截断 |
| --- | --- | --- |
| whisper 整片（`whisper_timestamped`） | **223×`う` / 30.0 s**，字数虚高 +168 | 无 |
| whisper 整片（openai-whisper） | 14 s 卡在 `カクー` | 无 |
| **Qwen 整片（A3）** | **0** | `BV1UBjq6fEgb` 丢尾部 **29 s / 183 字** |
| Qwen 逐段（A1） | 0 | 无 |
| whisper **生产（全工程）** | 0 | 无 |

`BV1ySjz6FEzD` 297.5–327.5 s：两个 whisper 实现**在同一段音频上都塌了**（形态不同），
说明是模型/解码器层面而非某个实现的问题；**生产的 VAD 分组 + 救援阶梯把它完全救回**
（12 条真实台词一条不少）。Qwen 在同一段不塌，但整片解码时会**静默截断**。

**结论：复读循环这一项 Qwen 确实更干净（0 vs 1，且 whisper 那次是 30 秒全丢），但它换了
一种失效方式，不是「更少失效」。两者都必须靠分窗工程才能用。** 样本为各 1 次事件，anecdotal。

## 6. gold 照出的生产端缺陷

1. **cue 时间倒挂**：`*-aligned.json` 有 49 处 segment 时间重叠（全部是词级重叠），
   43 处活过 `asr_stabilize` profile 0，最大 27 s。**已在 `to_srt` 兜底**（截断较早那条，
   绝不丢文字；发生时打 `Warning:`），**根因未修**——`extend_last_word_end_with_energy` 的
   `next_word_start` 只取同一 VAD interval 内的下一段，只解释得了 ≤1.0 s 的 29 处；
   另 20 处最大到 27.8 s，来自别处。见 `docs/vad-asr.md`。
2. **`premerge` 形同虚设**：在 11 个 clip 上**总共只并掉 1 条**（`skipped_no_evidence`
   否决了全部候选）。迁移 2.2 时一并测，没作用就删。
3. **`score_boundaries` 的禁切规则有个未写出的前提**：`b = inf` 的含义是「gap word 的归属
   已判定，不许拆」，前提是该边界**位于 segment 内部**。现行生产满足（段边界不经过 DP），
   但任何把候选集合扩到 segment 边界的改动都会造出静默的永不可切边界。**已经骗过一次。**
4. **幻觉复读区**：`kaguya60` 的 `音楽音楽…`、`BV1cJjE6cEt8` 的 29 秒 `おぉぉぉぉぉ`
   会吞掉其中的真台词。`asr_stabilize` 不删它们。

## 7. 已知欠账

- **全部人工裁决都是单人、无独立二标**：语义裁决两轮 96 条、gold 三批 1205 个标注位、
  对齐盲听 30 条。gold 批 2 做过 10.6% 自查（96.6%），但自复核不产出一致率。
  **这是全部结论里最薄的一环。** 首选二标窗口：`BV1kYLR6AEXv`（单独决定留出集一半的漏切、
  判据最难、无 `ok` 塌缩）。
- 目标 3 的重测只有 3 窗 48 `must`；批 3 五个窗口的 `ok` 仍偏低（10.0% vs 历史 20.3%）。
- 底噪归因用的是**分离后**的 vocal 轨，没回到源音频确认残留是 BGM 泄漏还是源本身就吵；
  11 个 clip 里只有 3 个能拿到 vocal flac。
- 全部结论限于**日语、VTuber 直播、11 个 clip**，没有英语基线可比。
