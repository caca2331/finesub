你在检查几份语音转写有没有漏掉说出的话。素材是日语节目（声优广播、游戏实况、对谈），录音是分离出来的人声轨。

每个片段给你：
- 一小段录音（几秒到十几秒），文件名就是片段编号；
- 几份转写（A、B、C…），每份列出它在这段时间附近写下的句子，每句前面标着相对片段开头的时间（秒，负数是片段开始之前）；
- 有时还有字幕组的参考字幕：它是人工整理过的，会删掉语气词、改写说法，只作参考，不是标准答案。

几份转写来自不同的系统，水平不一，可能每份都对，也可能只有一份对。不要因为多数转写写了或没写就下结论，以你听到的为准。

## 每个片段要判的

1. **heard**：先写下你在这段录音里听到了什么：原话（日语），谁在说（主要说话的人与插话的人，用「甲」「乙」区分即可）。听不清的地方写「（听不清）」。
2. **speech**：这段录音里有没有节目里的人在说话：
   - `正片`：节目的说话人在说话（包括短的附和、应答、笑着说的话）；
   - `背景`：只有背景里的人声，例如节目里播放的视频、游戏角色的语音、歌曲的歌词；
   - `无`：没有人声，只有音乐、音效或静音。
3. **kind**：如果有哪份转写漏了正片里的话，漏掉的部分是哪一类（几份漏的不同时取最重要的一类）：
   - `内容`：承载意思的词句；
   - `短反应`：独立的附和、应答（「うん」「はい」「へえ」「そうそう」）；
   - `填充`：语气词、口头禅、说错重来、重复、笑声；
   - 没有哪份漏：写 `-`。
4. **每份转写一行**，只看这段录音里说出的话：
   - `全`：这段里说出的话它都写下了。写法不同（汉字、假名、数字）、同音的写法、标点、语气词的有无，都算写下了。话写在了相邻的句子里（时间对不太上，但在前后两秒内），也算写下了。
   - `错写`：这里说的话它写了，但写成了别的词（听错、改写），意思不同。这也算写下了。
   - `漏一截`：这里说出的一部分话它没有写下，前后两秒的句子里也没有。用一句话写出漏了什么（原话）。
   - `整段漏`：这段里说出的话它一个字都没写下。
   - `多写`：它写了这段录音里没有说出的话（没有这句话、或是背景里的人声被当成了正片）。如果它同时漏了别的话，写漏的那一项，在说明里补一句多写。
   - 片段的 speech 是 `背景` 或 `无` 时，转写写了字就记 `多写`，没写就记 `全`。

只判片段范围里说出的话：片段开始之前、结束之后的话，即使转写没写，也不算漏。只漏了语气词、笑声、口头禅、说错又重说的那一半时，记 `漏一截`，kind 写 `填充`。

## 输出

每个片段输出一块，块与块之间空一行，块的顺序按片段编号：

```
<clip c03>
heard: 甲「それではですね、先日予告番組で告知された」乙「うん」
speech: 正片
kind: 短反应
A: 全
B: 漏一截 | 乙的「うん」
C: 全
D: 错写 | 「予告番組」写成了「予約番組」
</clip>
```

每块里 heard、speech、kind 各一行，然后每份转写恰好一行，写成 `字母: 判定` 或 `字母: 判定 | 说明`。判定只能是 `全`、`错写`、`漏一截`、`整段漏`、`多写` 之一。`漏一截` 必须写出漏了什么。
