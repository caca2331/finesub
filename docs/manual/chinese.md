# 中文素材：只纠错、统一简体

素材是中文时，LLM 阶段不翻译，每行写两版：忠实转写（只纠正听错的字词）与在它上面做的基础润色，成品字幕用润色版；识别出的文字统一写成简体。
不用加选项，按素材的语言自动决定。

```powershell
finesub input.mp4 --asr moss-local --language zh --stage final-srt
```

## 推荐怎么转写

- **请给 `--language zh`**：LLM 阶段靠素材的语言判断要不要翻译。不给时，本机 Whisper 按识别结果里每段的语言投票，一般也判得出；
  一体转写（`--asr`，含本地 MOSS）不给就不记语言，一定判不出。判不出时按翻译处理，打一行 `Warning:` 提醒加 `--language zh`。
- **有 RTX 30 系列或更新的显卡（8 GB 显存以上）就用本地 MOSS**（`--asr moss-local`，见[一体转写](joint-asr.md#本地-moss--asr-moss-local)）：
  2026-11 在 3 份中文剪段上，字错率（错字数 ÷ 人工字幕字数）本地 MOSS 0.151、云端 MOSS Pro 0.158、本机 Whisper 0.221。
  卡不够就用默认的本机 Whisper。

## LLM 阶段做什么

- **忠实转写**（`-corrected.srt`）：只改听错的字词（同音、近音、人名地名等专名）与标点，垫词与口吃照原话录下。说对了的字照原话写，说法照原样：不顺语法、不补字删字、不改量词和语序、不换同义词，口语里不合书面语法的说法也照留。
- **基础润色**（成品字幕）：在忠实转写上删掉垫词与口吃重复，把明显不通的口语顺成通顺的口语（量词、语序、多字漏字）；读得通的一字不改，不换说法、不改成书面语。整行只有垫词的行不进成品字幕。
- **两版都照留**：夹在中文里的外语照原样写；语气词和台湾腔、方言的说法照说话人的写法（「喔」「捏」「掰掰」不会被改成「哦」「呢」「拜拜」），只把繁体字改成简体。
- **风格只用写给中文纠错的**：风格档案节写了 `[任务] 中文纠错` 的才会用上（例如谐音梗加括注，括注只加在成品字幕里，忠实转写里没有），见
  [知识库「中文纠错用的风格」](knowledge.md#中文纠错用的风格)。别的风格多半是译法，不用；`--style` 点名的只读它的字幕长度档位。
  没有这样的风格时什么风格都不用，出厂默认风格也不用。`--extra-style` 这次不起作用（给了会提示一行）。字幕长短照常由
  `--split-length-scale`、点名风格的档位与 `config.toml` 定（见[调参](tuning.md#字幕太长--太短)）。
- **不校对**：`--llm-proofread auto` 不跑成品后的校对；写 `on` 照跑，但校对的说明是按翻译写的，效果没测过。
- **不用知识库**：知识库的词条是按翻译写的，中文任务这次不读也不写（`--knowledge` 按 `none`，给了 `read` / `update` 或 `--refined-srt` 会提示一行）。风格照用，见上。

## 产物

- 文件与阶段名都不变（[运行产物](outputs.md)）：`-corrected.srt` 是忠实转写，`-translated.srt` 与成品 `.srt` 是润色版；
  `-annotated.csv` 的 `corrected` 列是忠实转写、`translation` 列是润色版（整行垫词的行这一格是空的）。
- **简体**：Whisper 转中文时会成段写成繁体（大陆的素材也有 2–12% 的行），识别阶段最后一步统一转成简体，停在 `raw-srt` 也一样。
  本地 MOSS 与云端三家本来就出简体。不提供繁体输出。

## 不在范围内的

- **粤语**（`--language yue`）照旧翻译成简体中文：口语粤语转成书面中文本身就是翻译。
- **之前开始的任务**：这个版本之前开始纠错的中文任务续跑时照旧翻译。要改成只纠错，删掉 LLM 产物与
  `<名字>.llm-artifacts/` 目录再跑（[重跑某一阶段](outputs.md#重跑某一阶段需删除的产物)）。一个任务开始纠错时定下怎么做，
  之后续跑照它走，素材后来重转成别的语言也不变。
