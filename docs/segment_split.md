# 超长 segment 切分（DP 选点）

本文是切分打分与 gap word 调整的**规范文档**。生产实现在
`src/segment_split.py`，挂载于 `vad_asr` 的 aligned-JSON 阶段（重叠/零时长
清理之后、能量标注之前）；离线调参工具 `tools/split_explorer` 是其薄封装
（读现成 aligned/stable JSON + 缓存 VAD interval，不重跑 ASR，常量走 CLI）。
基于 whisper 段整体保留映射（`9da7c54`）与覆盖率救援（`f529345`）之后的
管线现状；实验依据来自 yui 系列对照（`out/yui-exp/`，2026-07）。

## 背景与动机

新映射把每个 whisper-timestamped 段整体保留、不在 VAD interval 边界切开。代价是
产生两类超长 segment：

- 时长/字数超过字幕友好范围（yui 44min 样本中 >8s 段 14–19 条，最长 ~14s）；
- 段内跨越大段静音（一个段横跨多个 interval 与其间 gap）。

实证（yui 样本 16 条超长段）：13/16 段内**零句读标点**；但全部含 2–8 个 VAD
断点。词级时间戳不完全可靠（涂抹、能量延长），VAD 边界是最高信任的切分候选；
解码器主动输出的空格（CJK 语境）是强断句信号。

## 总体形式：单段内 DP 求最低总分划分

对触发切分的 segment（词序列 w₁…wₙ，最终时间轴坐标）：

```text
F(j) = min over i<j { F(i) + B(i) + P(i+1..j) },  F(0) = 0，答案 F(n)
```

- `B(k)`：在 wₖ | wₖ₊₁ 之间落刀的边界分（可为负 = 奖励）。
- `P(a..b)`：片段分（时长 + 字数，U 形，理想区计 0）。
- 不切 = `P(1..n)`，自然参与比较；正常段会自己选择不切。
- 无硬上限、无窗口剪枝，纯 O(n²)；单段词数 <100，成本可忽略。

## 边界分 B(k) = a·(T(k) + G(g)) + 1 [+ 1 若非 VAD gap]，a = 1

`+1` 是每刀的基础成本；G 为负值折扣，B 可为负（强制切分）。**非 VAD gap
落刀（g = 0）额外 +1**（`no_gap_penalty`）：把刀推向 VAD 认证的真实静音，
interval 内部切分需要更强的长度压力或标点支撑才成立。

### 文本形态 T(k)

标点分类是共享单一事实源 `utils/text.py: punct_class()`（六类，方向感知，
切分与 gap word 胶合判定共用）：`sentence`（。．｡.！!？?…‥‼⁇⁈⁉）、
`clause`（、，,､；;：:）、`opening`（Ps/Pi:「『（【《 等，向右胶合）、
`closing`（Pe/Pf:」』）】》等，向左胶合）、`other`（・—等其余标点）、
`none`。空格判定用现成的 `space_before` 标注；CJK 语境空格分档更低
（日文等分句内不带空格的语言里，解码器主动输出的空格是强断句信号；
纯拉丁空格只是默认词界）。

切点看左词末字符（lc）与右词首字符（rc），按优先级取第一条命中：

| 切点形态 | T |
| --- | --- |
| **反向档**：lc=opening 或 rc=closing（拆散括号/引号胶合） | 1.5 |
| lc=sentence | 0 |
| lc=clause 或 lc=closing（引用闭合之后） | 0.2 |
| rc=opening（新引用开启之前） | 0.3 |
| lc=other 或 rc∈{sentence,clause,other} | 0.5 |
| 空格且两侧均为 CJK | 0.2 |
| 空格且仅一侧为 CJK | 0.5 |
| 其他（裸 CJK 词界、纯拉丁空格） | 1 |

gap word 胶合判定（`_boundary_is_separator`）用同一分类：opening 在左 /
closing 在右 = 强制胶合（压过一切分界信号）；其余标点任一侧出现即为分界；
空格按上述 CJK 规则。

### 间隙分 G(g)（连续递减，过阈值加速下降）

g 直接用**原始 VAD interval gap**（统一标尺；interval 内部切点 g=0，词级
时间戳的信任问题整个绕开；暂不做 energy 修正，效果不好再改）：

```text
g ≤ 0.5:  G(g) = −g          小停顿 = 弱正信号，线性小折扣
g > 0.5:  G(g) = −g² / 0.5   加速折扣，0.5 处连续（−0.5）
```

要点：

- g=1 时裸词界 B = 1−2+1 = 0（白切），g=1.5 时 B = −2.5 → **大静音是近乎
  强制的切分点**，即使片段长度达标也会被切开（治"字幕跨越沉默"）。
- 无下限（g 来自可信的 VAD gap，不会被涂抹时间戳伪造；巨大段内静音本就该
  无条件切）。
- 无停顿支撑的分句标点（B = 0.2+1+1 = 2.2，含非 VAD gap 罚）在无长度压力
  时不会被切——不做无谓切分。

## 片段分 P(c, d) = b·（四个铰链之和），b = 1

d = 调整后片段跨度（含内部小静音），c = `weighted_char_count`
（`src/subtitle_metrics.py`，拉丁/数字/标点/空格计 0.5）。
理想字数 5–20，可接受 3–36；理想时长 1.2–4.5s，可接受 0.6–8s。
**不设硬上限**——双铰链线性增长配合基础刀费，强制切分门槛实测落在
~8.5–9s，与"8s 可接受"吻合：

```text
时长过长: ((d>4.5)·(d−4.5) + (d>8)·(d−8)) / 3.5
字数过长: ((c>20)·(c−20) + (c>36)·(c−36)) / 16
时长过短: ((d<1.2)·(1.2−d) + (d<0.6)·(0.6−d)) / 0.6 / 2
字数过短: ((c<5)·(5−c) + (c<3)·(3−c)) / 2 / 2
```

理想区计 0 保证：把达标片段一分为二不降片段分、只多付边界分——没有长度
压力或大 gap 折扣时 DP 不会多切。过短罚在可接受边缘 0.5、过长罚在可接受
边缘 1.0 的不对称是有意的（字幕偏短比偏长便宜）。孤立感叹词两侧若各有
~1.5s gap，两刀折扣（约 −5）压过过短罚（约 2.5）→ 被隔离成独立小条，
是期望行为。

## gap word 调整策略（基于新映射的坐标语义）

打分用**有效坐标**（虚拟调整），只有被选中的切分点才物理改写片段边界；未触发
切分的段零扰动。

### 坐标区二分

由 intervals + 词坐标几何重建。合批音频结构：`interval A | 保留真实 gap 音频
(≤0.7s) | 0.3s 合成静音 | interval B`，映射回原时间轴后：

- **真实音频区** = interval 内 + 保留 gap 音频（`[A.end, A.end+min(gap,0.7)]`，
  1:1 映射）+ 组尾真实 pad：词坐标**一律采纳**，可做切点邻居、可做片段边缘，
  无特殊规则。
- **人造 gap 区** = 剩余 gap（合成静音的比例摊还区）：坐标纯虚构（对齐涂抹或
  幻觉），是唯一需要处理的对象。

### 人造区词的处理（按词与人造区的重叠形态分三种情况）

**情况 1：完全落在人造区，不 touch 两边** —— 纯虚构词（重涂抹或幻觉），
最严格：

- 归属按邻居定，默认作为下一 interval 首词的前缀（归右）——旧
  `_merge_gap_words_as_prefix` 判断的复活，但不合并词，保留词身份与 confidence。
- 落刀只允许在其**左侧**（作为归右前缀簇的开头随 B 走）；右侧禁刀
  （不得与所归属的 B 分离）；连续情况 1 词之间禁刀（B(k)=∞）。
- 永不做左片段末词；做右片段首词时坐标折叠进 `[B.start−0.14s, B 内首词 start]`
  的 lead-in 区间（0.14s 与 VAD 负 padding 一致），不许虚构坐标撑大片段。
- 虚构坐标不参与有效 gap 计量，也不缩减 VAD gap。
- 低置信（conf < ~0.35）且所在 gap 能量全程低于底噪 = 无声学支撑的幻觉：
  不删（超出切分职责），但坐标折叠进邻词跨度，不影响任何计量。

**情况 2：部分落在人造区，touch 一边** —— 跨界词，实的那端可信、虚的那端
不可信；归属 = touch 的那侧：

- **touch 左**（起点在真实音频区，词尾涂进人造区）：归左；起点原样采纳；
  词尾以能量核实 e* 为准（无能量轨时钳到真实区右边界
  `A.end + min(gap, 0.7)`）。可做左片段末词，其右侧落刀允许，
  有效 gap 从 e* 起算（即该词"吃掉"相应 VAD 间隙）。
- **touch 右**（词尾在 B 内或贴 B.start，起点涂进人造区）：归右；词尾原样
  采纳；起点钳进 `[B.start−0.14s, B.start]`。可做右片段首词，其左侧落刀
  允许，有效 gap 计到 B.start。

**文本胶合特例（优先于三种情况的默认归属）**：gap word 与邻词之间的
"分界"由文本判定——任一侧带标点即为分界；空格仅当边界两侧至少一侧为
CJK（或其他分句内不带空格语言）时算分界（两侧都是非 CJK 词时空格是默认
词界，不构成归属信号）。规则：

- gap word **前有分界、后无分界** → 归右（与后文胶合）；
- **前无分界、后有分界** → 归左（与前文胶合）；
- 两侧都有或都无分界 → 保持三种情况的默认归属；
- segment 首/尾边缘视为分界。

**同 gap 多个 gap word**：按胶合块整体处理——与左邻真实词无分界链相连的
前缀块整体归左，与右邻真实词无分界链相连的后缀块整体归右，夹在分界之间
的中间块保持默认归属；块内部（无分界处）禁刀，最终归属天然单调
（左块 … 中间 … 右块），gap 刀位落在归左块与归右块之间。

**禁刀规则统一化**：禁止切断任何 gap word 与其最终归属侧之间的边界
（归右词的右侧、归左词的左侧）；替代原"情况 1 右侧禁刀"的单条规则。

**情况 3：完全覆盖人造区，touch 两边** —— 词桥接整个 gap。注意人造区仅在
原始 gap > 0.7s 时存在，解码器从未听到中间的缺失音频——词不可能真的横跨
没听过的音频，跨越部分是 DTW 涂抹的定义性伪迹，真实归属必在一头：

- **并到真实接触时长更长的那一头**：比较左侧真实重叠（interval A 内 +
  A 后保留音频内）与右侧真实重叠（interval B 内）的时长，归较长侧，
  打平默认归右。
- 另一端按情况 2 对应方向的规则钳断：归左 → 词尾钳到 e*（能量核实）；
  归右 → 起点钳进 `[B.start−0.14s, B.start]`。
- 钳断后，被涂抹掩盖的 VAD 大 gap 重新暴露，该处的切分奖励（G 负值）
  恢复——这正是 DTW 最常把词拉过去的 VAD 边界，也是最值得切的位置；
  片段时长同样不再被虚构中段撑大。

### 有效 gap g(k) 的计量

**v1（现行）**：g 直接取原始 VAD interval gap——切点两侧词（按归属调整后）
分属 interval i 与 j 时，g = 两 interval 之间的总静音时长（j = i+1 时即
`s_j − e_i`）；同 interval 内 g = 0。标尺统一、来源可信，词级时间戳的
信任问题整个绕开。

**未来精化（效果不好再上）**：能量核实词尾 e*（从词尾向左找最后一个高于
静音底噪的帧，与 `extend_last_word_end_with_energy` 同一套机件反向用），
让真实尾音词按 e* 吃掉相应 VAD 间隙，剩余才是真静音；vad_asr 有能量轨时
精确，独立 asr_align 降级为词级 gap ×0.5 信任折扣。

### 落刀时的片段边界实现

- 左片段终点 = 末词调整后 end（允许伸入保留 gap 音频区——低能量尾巴保留，
  与 VAD 边界硬对齐的关键差异；未来 e* 精化后取能量核实词尾）。
- 右片段起点 = `B.start − 0.14s`；首词若为归右的人造区词，坐标压进 lead-in
  区间（前缀语义的坐标化表达）。
- 片段时间钳进来源 segment 的 `[start, end]`，零/负时长片段不进 SRT
  （与 `to_srt` 语义一致，兜住旧产物中的坐标残留）。

## 现状

- **生产**：`src/segment_split.py`，在 `vad_asr` 中于零时长延长之后、能量
  标注之前运行（`split_segments(segments, vad_intervals)`）。对全部 segment
  跑 DP（不切方案自然参与比较，单段词数 <100 成本可忽略）；未切分的段
  bit 不变。切分参数快照写入 `metadata.asr_align.segment_split`。
- **片段字段**：`lang` / `confidence` / `no_speech_prob` 继承来源段整体值
  （指标语义稀释，见 `docs/vad-asr.md` 标注）；
  `vad_weighted_energy_db` 在切分**之后**按片段自身边界计算，无稀释。
- **切分起源 tag**：首片之外的每个片段追加 segment 级
  `tags: ["splitted_before"]`（`SPLIT_TAG`）——描述"本段起点由 split 切出"这一
  段自身属性（左邻后续被 stabilize 删除也不改写）。stabilize profile 3 的预合并
  据此结构性拒绝重新接回 split 刻意制造的边界（`docs/asr-stabilize.md`）。
- **case3 锚定默认 = 右**（2026-07-19 改，替换「真实音频接触较长侧」启发式）：wt 的
  拉伸病理会把右词组首词的 raw 跨度往左填满停顿（真|ん中、カ|ウントダウン、隣|から），
  其左接触必然更长，旧启发式在该形态上系统性锚左错。真正属左的话语收尾词（…です。）
  是「左胶连+右分隔」形态，pass 2 先于默认锚左；两侧全胶的终助词拖尾（…だよ|ね）是
  显式接受的残余风险（16 例研究零实例、损害轻微、有 tag 可审计）。16 例复演：15 对 +
  1 无差别（あー!），0 错。
- **gap word 调整溯源**：凡 case ≠ real 的词在产物里保留
  `split_adjust_case`（case1/case2L/case2R/case3）、`split_anchor`（left/right）、
  `split_anchor_source`（glue=pass2 胶连定向 / default=case 默认）；坐标确实被移动时
  另存 `raw_start`/`raw_end`（wt 原始词时）。未调整的 real 词不带这些字段。片段首词为
  「case3 且纯默认归右」时，该片段追加段级 tag `split_anchor_uncertain`（审计存证，
  将来可选作 LLM 提示）。用途：产物取证时能直接区分「wt 原生错置」与「zone 锚定所致」，
  无需反推 VAD 几何。
- **调参**：`tools/split_explorer`（按需维护）是生产模块的薄封装，常量走
  CLI 参数，读现成 JSON + 缓存 interval，纯 CPU 秒级重跑。
- 行为核对（yui 实证）：无标点超长段的切点落在 VAD 认证的大 gap 上
  （裸词界 T=1 + 基础刀费 1，g≥1 时 G≤−2 → B≤0）；有标点段则标点+停顿
  共振点优先；非 VAD gap 落刀 +1 后，无 gap 无标点的 ~8.5s 内长句
  容忍不切。

## 待细化（评审点）

- 常量取值待原型校准：a / b / 基础刀费 1 / G 拐点 0.5 / 铰链区间。
- 合成词（repeat 清理产物）做切点邻居是否加罚（原稿曾设 +1，现版未纳入）。
- 情况 1（纯虚构词）归属的例外情形：是否需要归左（作为 A 尾词）的判定
  （当前默认全部归右；情况 2/3 已按 touch/重叠侧自然归属）。
- 与 recall/覆盖率救援产物的交互：救援产物边界已较碎，是否豁免切分。
- beam 救援产物（naive 对齐、词时戳更不可信）是否需要额外信任折扣。
- 片段 `confidence`/`no_speech_prob` 继承来源段整体值的语义标注。
