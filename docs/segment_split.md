# 字幕分句（全局 DP 选点）

本文是分句打分与 gap word 调整的**规范文档**。生产实现在
`src/asr_playground/speech/postprocessing/segmentation.py`，挂载于
`src/asr_playground/speech/recognition/stage.py` 的 aligned-JSON 阶段（重叠/零时长
清理之后、能量标注之前）；离线调参工具 `tools/split_explorer` 是其薄封装
（读现成 aligned/stable JSON + 缓存 VAD interval，不重跑 ASR，常量走 CLI）。

**分句器接管字幕的分段权**：DP 在整个 clip 的词流上求最低总分划分，ASR 自己的分段
接缝只是其中带折扣的候选边界。所以它既能切开一个 ASR 段，也能把相邻 ASR 段合成一条
字幕——输出的段与 ASR 的段没有包含关系。

基于 whisper 段整体保留映射（`9da7c54`）与覆盖率救援（`f529345`）之后的
管线现状；实验依据来自 yui 系列对照（`out/yui-exp/`，2026-07）与 9 clip 测试床
（8 BV + yui）。

## 背景与动机

ASR 的分段不是为字幕设计的，两个方向都不合用。

**切**——whisper 段整体保留映射不在 VAD interval 边界切开，代价是两类超长 segment：

- 时长/字数超过字幕友好范围（yui 44min 样本中 >8s 段 14–19 条，最长 ~14s）；
- 段内跨越大段静音（一个段横跨多个 interval 与其间 gap）。

实证（yui 样本 16 条超长段）：13/16 段内**零句读标点**；但全部含 2–8 个 VAD
断点。词级时间戳不完全可靠（涂抹、能量延长），VAD 边界是最高信任的切分候选；
解码器主动输出的空格（CJK 语境）是强断句信号。

**并**——ASR 也会在不该断的地方断（典型是词中切断，碎片天然低置信，下游噪音判定会
把它当幻觉丢弃、词永久残缺）。逐段作用域对此完全无能为力：它只能切，不能并。全局作用域
把接缝纳入同一套代价比较后，这类边界由 DP 自己合回去——这也是独立的确定性预合并 pass
（原 `premerge.py` / stabilize profile 3）被删除的原因，见 `docs/asr-stabilize.md`。

## 总体形式：DP 求最低总分划分

对整个 clip 的词序列（w₁…wₙ，最终时间轴坐标；ASR 段接缝是其中打了折扣的普通边界）：

```text
F(j) = min over i<j { F(i) + B(i) + P(i+1..j) },  F(0) = 0，答案 F(n)
```

- `B(k)`：在 wₖ | wₖ₊₁ 之间落刀的边界分（可为负 = 奖励）。
- `P(a..b)`：片段分（时长 + 字数，U 形，理想区计 0）。
- 不切 = `P(1..n)`，自然参与比较；正常段会自己选择不切。
- O(n²)，内层由 `max_piece_sec` 剪枝（可证无损，见「复杂度界」节）。

## 边界分 B(k) = a·(T(k) + S(k)) + 1，a = 1

`+1` 是每刀的基础成本；形态项 S 为负值折扣时 B 可为负（强制切分）。S 走哪条式子由
**该边界是不是 VAD gap**（右词 anchor > 左词 anchor）决定——两把尺，不是一把尺的两段：

- **跨 VAD interval**：`S = G(g)`，g 为原始 VAD gap（见下）。VAD 已经给了边界，
  即使静音量算得 0 也走这条。
- **同一 interval 内**：VAD 根本没在这里给边界，改用对齐器的**词级停顿**
  `pause = max(0, 右词.raw_start − 左词.raw_end)`（必须取原始词时戳，pass 3 改写后的
  坐标是锚定的函数而非解码器听到的东西）：

      S = max(−1, (non_vad_gap_penalty if pause == 0 else 0) − pause²)

  `pause = 0` 时 `S = +1`，即旧的 `no_gap_penalty` 阶跃罚则——把刀推向 VAD 认证的
  真实静音，interval 内部切分需要更强的长度压力或标点支撑才成立。`pause > 0` 则免罚
  并按停顿平方加速给折扣，`−1` 地板防止长词停压过一切。地板与二次项的取值依据见「参数标定」节。

### 文本形态 T(k)

标点分类是共享单一事实源 `src/asr_playground/text.py: punct_class()`（六类，方向感知，
切分与 gap word 胶合判定共用）：`sentence`（。．｡.！!？?…‥‼⁇⁈⁉）、
`clause`（、，,､；;：:）、`opening`（Ps/Pi:「『（【《 等，向右胶合）、
`closing`（Pe/Pf:」』）】》等，向左胶合）、`other`（・—等其余标点）、
`none`。空格判定用现成的 `space_before` 标注；CJK 语境空格分档更低
（日文等分句内不带空格的语言里，解码器主动输出的空格是强断句信号；
纯拉丁空格只是默认词界）。

切点看左词末字符（lc）与右词首字符（rc），按优先级取第一条命中：

| 切点形态 | T |
| --- | --- |
| **反向档**：lc=opening 或 rc=closing（拆散括号/引号胶合） | 1.5 |
| lc=sentence | 0 |
| lc=clause 或 lc=closing（引用闭合之后） | 0.2 |
| rc=opening（新引用开启之前） | 0.3 |
| lc=other 或 rc∈{sentence,clause,other} | 0.5 |
| 空格且两侧均为 CJK | 0.2 |
| 空格且仅一侧为 CJK | 0.5 |
| 其他（裸 CJK 词界、纯拉丁空格） | 1 |

gap word 胶合判定（`_boundary_is_separator`）用同一分类：opening 在左 /
closing 在右 = 强制胶合（压过一切分界信号）；其余标点任一侧出现即为分界；
空格按上述 CJK 规则。

### 间隙分 G(g)（连续递减，过阈值加速下降）

g 直接用**原始 VAD interval gap**（统一标尺；interval 内部切点 g=0，词级
时间戳的信任问题整个绕开；暂不做 energy 修正，效果不好再改）：

```text
g ≤ 0.5:  G(g) = −g          小停顿 = 弱正信号，线性小折扣
g > 0.5:  G(g) = −g² / 0.5   加速折扣，0.5 处连续（−0.5）
```

要点：

- g=1 时裸词界 B = 1−2+1 = 0（白切），g=1.5 时 B = −2.5 → **大静音是近乎
  强制的切分点**，即使片段长度达标也会被切开（治"字幕跨越沉默"）。
- 无下限（g 来自可信的 VAD gap，不会被涂抹时间戳伪造；巨大段内静音本就该
  无条件切）。
- 无停顿支撑的分句标点（B = 0.2+1+1 = 2.2，含非 VAD gap 罚）在无长度压力
  时不会被切——不做无谓切分。

**为什么 `g = 0` 必须裂开成两把尺**：`interval_gap_between` 首行 `if j <= i: return 0.0`，
两词只要 anchor 到同一 interval，`g` 恒为 0，不论实际隔多久（能量 VAD 会把没跌破阈值的
停顿并进同一区间）。全测试床段内 25114 个边界里 `g = 0` 占 **24588（97.9%）**，排序只剩
`t_score` 的六个离散值。词级停顿在其中一部分位置是有信号的（`must` 中位 +0.195s vs 推定
禁切 +0.000s），按它裂开即可恢复一维分辨率。二次项在现有 gold 上不产生差异（`g = 0` 桶只
含短停顿——停顿一长 VAD 就切开了），采用它是为了覆盖该桶展示不了的失效模式：人声分离残留
抬高底噪、能量 VAD 漏语音的素材（`yingtao`，非语音 −48.7 dB）会让 0.5–0.9s 词停与 `g = 0`
并存。判据写成 `g > 0` 而非「是不是 VAD gap」会把相接 interval（跨区间但静音量 0）错送进
词级停顿分支——本测试床上 0 例（19239 个段内边界），但换个 VAD 就会静默漂移。

## 片段分 P(c, d) = b·（四个铰链之和），b = 1

d = 调整后片段跨度（含内部小静音），c = `weighted_char_count`
（`src/asr_playground/subtitles/metrics.py`，拉丁/数字/标点/空格计 0.5）。
理想字数 5–20，可接受 3–36；理想时长 1.2–4.5s，可接受 0.6–8s。
**不设硬上限**——双铰链线性增长配合基础刀费，强制切分门槛实测落在
~8.5–9s，与"8s 可接受"吻合：

```text
时长过长: ((d>4.5)·(d−4.5) + (d>8)·(d−8)) / 3.5
字数过长: ((c>20)·(c−20) + (c>36)·(c−36)) / 16
时长过短: ((d<1.2)·(1.2−d) + (d<0.6)·(0.6−d)) / 0.6 / 2
字数过短: ((c<5)·(5−c) + (c<3)·(3−c)) / 2 / 2
```

理想区计 0 保证：把达标片段一分为二不降片段分、只多付边界分——没有长度
压力或大 gap 折扣时 DP 不会多切。过短罚在可接受边缘 0.5、过长罚在可接受
边缘 1.0 的不对称是有意的（字幕偏短比偏长便宜）。孤立感叹词两侧若各有
~1.5s gap，两刀折扣（约 −5）压过过短罚（约 2.5）→ 被隔离成独立小条，
是期望行为。

## gap word 调整策略（基于新映射的坐标语义）

打分用**有效坐标**（虚拟调整），只有被选中的切分点才物理改写片段边界；未触发
切分的段零扰动。

### 坐标区二分

由 intervals + 词坐标几何重建。合批音频结构：`interval A | 保留真实 gap 音频
(≤0.7s) | 0.3s 合成静音 | interval B`，映射回原时间轴后：

- **真实音频区** = interval 内 + 保留 gap 音频（`[A.end, A.end+min(gap,0.7)]`，
  1:1 映射）+ 组尾真实 pad：词坐标**一律采纳**，可做切点邻居、可做片段边缘，
  无特殊规则。
- **人造 gap 区** = 剩余 gap（合成静音的比例摊还区）：坐标纯虚构（对齐涂抹或
  幻觉），是唯一需要处理的对象。

### 人造区词的处理（按词与人造区的重叠形态分三种情况）

**情况 1：完全落在人造区，不 touch 两边** —— 纯虚构词（重涂抹或幻觉），
最严格：

- 归属按邻居定，默认作为下一 interval 首词的前缀（归右）——旧
  `_merge_gap_words_as_prefix` 判断的复活，但不合并词，保留词身份与 confidence。
- 落刀只允许在其**左侧**（作为归右前缀簇的开头随 B 走）；右侧禁刀
  （不得与所归属的 B 分离）；连续情况 1 词之间禁刀（B(k)=∞）。
- 永不做左片段末词；做右片段首词时坐标折叠进 `[B.start−lead_in, B 内首词 start]`
  的 lead-in 区间（`SPLIT_LEAD_IN_SEC` 直接由 VAD 的 `NEGATIVE_PAD_RIGHT_MS` 推导，
  现为 0.14s），不许虚构坐标撑大片段。
- 虚构坐标不参与有效 gap 计量，也不缩减 VAD gap。
- 低置信（conf < ~0.35）且所在 gap 能量全程低于底噪 = 无声学支撑的幻觉：
  不删（超出切分职责），但坐标折叠进邻词跨度，不影响任何计量。

**情况 2：部分落在人造区，touch 一边** —— 跨界词，实的那端可信、虚的那端
不可信；归属 = touch 的那侧：

- **touch 左**（起点在真实音频区，词尾涂进人造区）：归左；起点原样采纳；
  词尾以能量核实 e* 为准（无能量轨时钳到真实区右边界
  `A.end + min(gap, 0.7)`）。可做左片段末词，其右侧落刀允许，
  有效 gap 从 e* 起算（即该词"吃掉"相应 VAD 间隙）。
- **touch 右**（词尾在 B 内或贴 B.start，起点涂进人造区）：归右；词尾原样
  采纳；起点钳进 `[B.start−0.14s, B.start]`。可做右片段首词，其左侧落刀
  允许，有效 gap 计到 B.start。

**文本胶合特例（优先于三种情况的默认归属）**：gap word 与邻词之间的
"分界"由文本判定——任一侧带标点即为分界；空格仅当边界两侧至少一侧为
CJK（或其他分句内不带空格语言）时算分界（两侧都是非 CJK 词时空格是默认
词界，不构成归属信号）。规则：

- gap word **前有分界、后无分界** → 归右（与后文胶合）；
- **前无分界、后有分界** → 归左（与前文胶合）；
- 两侧都有或都无分界 → 保持三种情况的默认归属；
- segment 首/尾边缘视为分界。

**同 gap 多个 gap word**：按胶合块整体处理——与左邻真实词无分界链相连的
前缀块整体归左，与右邻真实词无分界链相连的后缀块整体归右，夹在分界之间
的中间块保持默认归属；块内部（无分界处）禁刀，最终归属天然单调
（左块 … 中间 … 右块），gap 刀位落在归左块与归右块之间。

**禁刀规则统一化**：禁止切断任何 gap word 与其最终归属侧之间的边界
（归右词的右侧、归左词的左侧）；替代原"情况 1 右侧禁刀"的单条规则。

**情况 3：完全覆盖人造区，touch 两边** —— 词桥接整个 gap。注意人造区仅在
原始 gap > 0.7s 时存在，解码器从未听到中间的缺失音频——词不可能真的横跨
没听过的音频，跨越部分是 DTW 涂抹的定义性伪迹，真实归属必在一头：

- **并到真实接触时长更长的那一头**：比较左侧真实重叠（interval A 内 +
  A 后保留音频内）与右侧真实重叠（interval B 内）的时长，归较长侧，
  打平默认归右。
- 另一端按情况 2 对应方向的规则钳断：归左 → 词尾钳到 e*（能量核实）；
  归右 → 起点钳进 `[B.start−0.14s, B.start]`。
- 钳断后，被涂抹掩盖的 VAD 大 gap 重新暴露，该处的切分奖励（G 负值）
  恢复——这正是 DTW 最常把词拉过去的 VAD 边界，也是最值得切的位置；
  片段时长同样不再被虚构中段撑大。

### 有效 gap g(k) 的计量

**跨 VAD interval 时**：g 直接取原始 VAD interval gap——切点两侧词（按归属调整后）
分属 interval i 与 j 时，g = 两 interval 之间的总静音时长（j = i+1 时即
`s_j − e_i`）。标尺统一、来源可信，词级时间戳的信任问题整个绕开。

**同一 interval 内**不计 g（`interval_gap_between` 返回 0），改由词级停顿承担分辨率，
见「边界分」节的 S(k)。**注意这两条归零路径互不相干**：`j <= i`（同区间，VAD 没给边界）
与真实跨区间但静音量算得 0（相邻 interval 恰好相接）语义完全不同，判据必须按 anchor 比较
而不是按 `g` 的数值——否则后者会被错送进词级停顿分支。

**未来精化（效果不好再上）**：能量核实词尾 e*（从词尾向左找最后一个高于
静音底噪的帧，与 `extend_last_word_end_with_energy` 同一套机件反向用），
让真实尾音词按 e* 吃掉相应 VAD 间隙，剩余才是真静音；vad_asr 有能量轨时
精确，独立 asr_align 降级为词级 gap ×0.5 信任折扣。

### 落刀时的片段边界实现

- 左片段终点 = 末词调整后 end（允许伸入保留 gap 音频区——低能量尾巴保留，
  与 VAD 边界硬对齐的关键差异；未来 e* 精化后取能量核实词尾）。
- 右片段起点 = `B.start − 0.14s`；首词若为归右的人造区词，坐标压进 lead-in
  区间（前缀语义的坐标化表达）。
- 片段时间钳进其覆盖的来源 segment 的并集 `[min(start), max(end)]`，零/负时长片段不进
  SRT（与 `asr_playground.subtitles.rendering` / `to-srt` 语义一致，兜住旧产物中的坐标残留）；详见「跨段片段的字段继承」节。

## 生产落位与产物字段

- **生产**：`src/asr_playground/speech/postprocessing/segmentation.py`，在 recognition stage 中于零时长延长之后、能量
  标注之前运行（`split_segments(segments, vad_intervals)`）。**DP 跨整个 clip 全局
  求解**：每条 ASR 段接缝都是普通候选边界，只是打了 `whisper_segment_bonus` 折扣。
  词分类与段内打分仍严格逐段（等价性前提，见「全局作用域」节）。DP 被 piece 时长上界
  `max_piece_sec` 剪枝（可证无损）。切分参数快照写入
  `metadata.asr_align.segment_split`。
- **片段字段**：`lang` / `confidence` / `no_speech_prob` 按各来源段贡献的**词数加权**
  继承（数值取加权均值、类别取加权众数）；单来源片段即原样继承，与旧行为逐字段相同
  （指标语义稀释，见 `docs/vad-asr.md` 标注）。
  `vad_weighted_energy_db` 在切分**之后**按片段自身边界计算，无稀释。
  `fw-refine` 的 `alignment_events[]` 不做加权或复制：以 refined start / peak / span 中点为锚点，
  每条事件在切并后只归属最近的一条输出片段；无时间字段的 segment 级事件用来源段中点定位。
- **分段起源标记**：每条 ASR 源段的**首词**打词级 `whisper_segment_start: true`。
  这是产物里唯一无法从别处恢复的信息——全局 DP 可以把整条接缝吞进 piece 内部，
  段级字段表达不了。据此可重建原始 ASR 分组（`regroup_by_whisper_segments`），
  `split_segments` 入口检测到该标记会先重组，因此**对自身输出幂等**。
  互补的稀有事实单独打段级 tag `mid_segment_start`：片段起点**不是** ASR 段边界，
  即 DP 在段内部切的刀（实测 31/2347，正面事实则覆盖 98% 的段、无区分力）。
- **case3 锚定默认 = 右**（2026-07-19 改，替换「真实音频接触较长侧」启发式）：wt 的
  拉伸病理会把右词组首词的 raw 跨度往左填满停顿（真|ん中、カ|ウントダウン、隣|から），
  其左接触必然更长，旧启发式在该形态上系统性锚左错。真正属左的话语收尾词（…です。）
  是「左胶连+右分隔」形态，pass 2 先于默认锚左；两侧全胶的终助词拖尾（…だよ|ね）是
  显式接受的残余风险（16 例研究零实例、损害轻微、有 tag 可审计）。16 例复演：15 对 +
  1 无差别（あー!），0 错。
- **gap word 调整溯源**：凡 case ≠ real 的词在产物里保留
  `split_adjust_case`（case1/case2L/case2R/case3）、`split_anchor`（left/right）、
  `split_anchor_source`（glue=pass2 胶连定向 / default=case 默认）；坐标确实被移动时
  另存 `raw_start`/`raw_end`（wt 原始词时）。未调整的 real 词不带这些字段。片段首词为
  「case3 且纯默认归右」时，该片段追加段级 tag `split_anchor_uncertain`（审计存证，
  将来可选作 LLM 提示）。用途：产物取证时能直接区分「wt 原生错置」与「zone 锚定所致」，
  无需反推 VAD 几何。
- **调参**：`tools/split_explorer`（按需维护）是生产模块的薄封装，常量走
  CLI 参数，读现成 JSON + 缓存 interval，纯 CPU 秒级重跑。
- **未被 DP 改动的段原样输出**：片段恰好等于一整条来源段时直接沿用该段（只补词级
  标记），gap word 调整对它保持虚拟——「未触发切分的段零扰动」这条性质在全局作用域下
  依然成立。
- **缺 word timestamps 的文本段不丢弃**：若 segment 文本非空、start/end 有效但
  `words` 为空，入口以整段文本和整段时间合成一条 word，并标记
  `synthetic_from_segment: true`。该标记说明它只是数据完整性兜底，不是真实词级对齐；
  单 word 段自然不会被内部切分。连这一归一化也无法安全完成时，整批输入原样返回，
  不跨过未知段做全局合并。发生数量记录在
  `metadata.asr_align.segment_split.synthetic_word_segments`。
- 行为核对（yui 实证）：无标点超长段的切点落在 VAD 认证的大 gap 上
  （裸词界 T=1 + 基础刀费 1，g≥1 时 G≤−2 → B≤0）；有标点段则标点+停顿
  共振点优先；无词停的非 VAD gap 落刀 +1 后，无 gap 无标点的 ~8.5s 内长句
  容忍不切。

## 全局作用域与 ASR 分段奖励

DP 求解跨**整个 clip**：ASR（whisper）分段的接缝是其中的普通候选边界，只是减去一个
`whisper_segment_bonus = 4.5` 的折扣。分段器因此既能在段内切，也能把相邻 ASR 段合成一条
字幕——后者是逐段作用域根本做不到的动作。

**词分类与段内打分严格保持逐段**，只有 `dp_split` 跨段：

    for seg in segments:  adj_i = adjust_words(seg);  bounds_i = score_boundaries(adj_i)   # 逐段
    拼接 adj / bounds，在每个接缝插入一条**现算**的边界，一次 dp_split(adj, bounds)

> ⚠️ **这条不变量必须守住。** 把 `adjust_words` / `score_boundaries` 放到拼接流上算，会改掉
> 25297 个段内边界中的 17 个，其中数处在 `inf`（禁切）与大负数之间翻转——因为 pass 2 的胶合
> run 把词表首尾当作分界（逐段时那正是段边界），且全局排序会在 segment 时间重叠处改变词序。
> 它同时是「`whisper_segment_bonus → ∞` 退化为逐段切分」这条等价性的前提。

接缝边界**现算**，两端取左段末词 / 右段首词的 `AdjWord`，规则与段内边界完全相同
（`boundary_score`），再减去 bonus：

    b = a*(t + S) + base − whisper_segment_bonus      ← bonus 只减在接缝上

**接缝边界永远不是 `banned`**：`banned`（`b = inf`）只由 `score_boundaries` 在段内产生，
任何 bonus 都减不动它。若接缝可能被禁切，就会出现「无论 bonus 多大都切不开的 ASR 边界」。
现算而非复用段内结果，正是为了绕开这一点。

### 参数标定（14 窗 gold，留出 163 `must`）

| 臂 | 留出必切 | 刀 | 违反 | 逐窗 `must` 好/平/坏 | 逐窗违反 好/平/坏 |
| --- | --- | --- | --- | --- | --- |
| 逐段作用域 + 阶跃罚则（旧） | 155/163 | 412 | 132 | — | — |
| 仅词级停顿项（仍逐段） | 156/163 | 412 | 131 | 1/13/0 | 2/12/0 |
| **现行（全局 + bonus 4.5 + 停顿项）** | **156/163** | **403** | **122** | **1/13/0** | **6/8/0** |

相对旧行为 **+1 `must`、−9 刀、−10 违反（−7.6%），14 个窗口无一在任一轴变差**。
`whisper_segment_bonus` 的严格区间是 **4.5–7**（≤4 起有窗口变差，≥7 退回逐段）；
`non_vad_gap_penalty` 的平台是 **0.75–1.0**（≥1.5 起毁 `must`，3.0 时拟合集 58→48）。
`penalty = 1.0` 恰在平台边缘——**这个数值本身一直是对的，从前错的是它的触发条件**
（见「边界分」节：旧实现按 `g <= 0` 收罚，而非按「VAD 是否给了边界」）。

收益的分解（决定了作用域改动本身值不值）：

    仅免罚（bonus=7，此时全局已等价逐段）   +1 must,  −1 违反   ← 判据修正
    仅全局 DP + bonus 4.5                  −1 must, −11 违反   ← 减过切必付漏切
    两者合起来                             +1 must, −10 违反   ← 互补

**架构改动单独只值 −2 违反**（`bonus` 5.5–6 的严格不劣区间），其余收益来自判据修正——
而判据修正并不需要全局 DP。重开同类讨论时先读这一行。

### 复杂度界 `max_piece_sec = 20.0`

`dp_split` 是 O(n²)。逐段时 n≈10–40 可忽略，全局则是整个 clip：未加界的原型跑 `yui`
7008 词需 ≈77 s，3 小时直播约 25× → 半小时，不可接受。内层循环因此加界，**界定在时长上，
因为时长上可证，词数上不可证**：

单刀最大代价（禁切除外）`b_max = a·(t_max + s_max) + base = 1·(1.5 + 1) + 1 = 3.5`。
把一个超长 piece 对半切、两半仍在 `ok_hi` 之上时省下的量，闭式是
`(ideal_hi + ok_hi) / (ok_hi − ideal_hi)`：

| 铰链 | 省下 | vs `b_max = 3.5` |
| --- | --- | --- |
| 时长 (4.5, 8.0) | `12.5 / 3.5 = ` **3.5714** | **> 3.5 ✔ 严格更优** |
| 字数 (20, 36) | `56 / 16 = ` **3.5** | **= 3.5 ✘ 恰好持平** |

所以**任何 `d > 2·dur_ok_hi = 16 s` 的 piece，只要内部存在一个非禁切边界，必定可以通过切分
严格降低总代价**；取 `d ≤ 20 s` 作内层界可证无损，且自适应语速。字数一侧恰好持平——持平意味着
最优值相同、只影响取到哪个最优解，不构成损失。实测印证（全测试床 3347 个 piece）：

| | 中位 | p99 | 最大 | 理论界 |
| --- | --- | --- | --- | --- |
| 时长 (s) | 1.7 | 5.8 | **9.3** | 16（取 20 → 2.15× 余量） |
| 加权字数 | 10 | 33 | **53** | 72（= 2×`chars_ok_hi`） |
| 词数 | 7 | 26 | **46** | 无定理界 |

按词数取 `K=120` 实践上也够（2.6× 余量），但那是经验界，时长界是定理。

**实现**：内层自 `j-1` 向下扫、越界即 `break`。`break` 的合法性靠**词起点的前缀最大值**
（`start_max`，单调不减）而非 `adj[i].start` 本身——后者在 segment 时间重叠处可以非单调，
直接 `break` 会漏掉合法前驱。`start_max[i] >= adj[i].start`，故估出的时长只会偏短、被剪掉的
piece 必定真的超界，剪枝仍然无损。`i == j-1` 永远参与（单个超长词仍能自成 piece）；若界内
候选全被禁切则回退一次全扫描，保证 DP 恒有解。逐段路径上该界是 no-op（实测最长 piece 9.3 s）。
现行实测：`yui` 7008 词 / 667 段全局 DP **1.5 s**。

### 跨段片段的字段继承

全局作用域下 piece 可以跨越多个来源段。影响面（9 clip 测试床，2347 piece）：

| | 数量 | 占比 |
| --- | --- | --- |
| **跨 ≥2 个源段的 piece** | **56** | **2.4%**（逐 clip 0–6.6%，2 个 clip 为 0） |
| 跨 2 段 / 跨 3 段 | 52 / 4 | 从无 >3 |
| 被吞掉的接缝 | 60 | 2.5%（共 2368 条接缝） |
| `lang` 在被跨来源间不一致 | **0 / 56** | — |
| `confidence` 在来源间的落差 | 中位 0.262，最大 0.807 | 唯一真在变的字段 |

`confidence` 的下游只有一处：
`asr_playground.speech.postprocessing.stabilization._profile_2_tags` 的 `low_conf`，且它是
**`段级 conf < 0.3` AND `词级加权 conf < 0.3`** 的合取，再 AND 能量才导致丢弃。56 条跨段
piece 里 **49 条的词级置信 ≥ 0.3，闸门根本不通电**；剩下 7 条里任意两条候选规则
（first/last/min/max/dominant/加权均值）之间的分歧**至多 1 条**——**全床 2347 条 piece 里，
规则选择的可观测影响 ≤ 1 条**。所以规则只需讲得通、可判定、无需 tiebreak。

**规则：按各来源贡献的词数加权，一条规则覆盖三个字段。**

    数值型（confidence / no_speech_prob）：加权算术平均
    类别型（lang）：                       加权众数，平票取时间靠前的来源

理由按重要性排：

- **单来源时权重恒为 1，逐字段等于直接继承**——被「`bonus → ∞` 逐刀等于逐段」的等价性回归
  自动覆盖，不必为 97.6% 的 piece 单独论证。
- Whisper 的段级 `confidence` 本来就≈其词置信的加权聚合（yui 667 段：中位差 −0.004，
  68.5% 落在 ±0.02 内），所以「按词数重建这个 span 的聚合值」是它原有的语义。
- **不需要 tiebreak**。「按词数最多者继承」看着自然，但实测 23/56 没有明显多数、20/56 落在
  0.45–0.55 的准平票区，等于要再补一条仲裁规则去决定一件无关紧要的事。
- 不把 piece 往丢弃方向推：取 `min` 会把「闸门通电」的 piece 从 8 条抬到 18 条。跨段 piece 是
  DP 判定为一体的东西，让它因为某个 parent 低置信而被丢掉是错的方向。

实现上，各来源取值全相等时**直接返回该值而不做平均**——重组后每个重建源段拿到的是同一个值，
再平均会在末位漂移、破坏幂等。

两条脚注：`no_speech_prob` 严格说是 log 尺度消费的（`src/asr_playground/speech/recognition/transcribe.py`
的 `ROUND_DIGITS_BY_KEY`
注释），加权算术均值偏向大值——无所谓，因为 `src/` 里没有任何消费者，它是纯取证字段，不值得
单开一条几何均值规则；`lang` 的 0 分歧是因为语言检测是 group 级的
（`_collapse_group_language_entries`），相邻段天然同语言，规则写全是为了确定性而非这个测试床。

**钳位边界：`[min(各来源 start), max(各来源 end)]`。** 用 min/max 而不是「首来源.start /
末来源.end」，代价为零且不依赖段序单调（生产里 `clamp_segment_overlaps` 保证了单调，但
`-aligned-gap03` 这类历史产物实测有重叠段——别把不变量押在上游）。实测钳位在全床触发
**17 次，全部落在单来源 piece 上**（gap word 词尾伸进保留 gap 音频、超出源段 `end`）：并集
钳位对单来源行为逐位保持，对跨段 piece 从不生效。

### 分段起源标记为什么在词级

全局 DP 之后，「本段起点由分段器切出」对每个片段都成立，失去区分力；真正**不可从产物恢复**的
是「这里原本是 ASR 的分段边界」。而**段级字段承载不了它**：被吞掉的那 60 条接缝落在 piece
内部，只有词能标位置。所以标记落在词级 `whisper_segment_start`，段级只发互补的稀有事实
`mid_segment_start`（起点不是 ASR 边界，实测 31/2347；正面事实覆盖 2308/2347 ≈ 98%，
几乎没有区分力，且可直接从词标记读出）。

由此，「这个 piece 跨了几个源段」也**可从产物推断**（内部出现该词标记的次数 = 来源数 − 1），
不必再落 `split_source_count` 之类的字段。

### 幂等性

`split_segments` 入口检测到 `whisper_segment_start` 即先调 `regroup_by_whisper_segments`
还原 ASR 原生分组，再走正常流程；**因此对自身输出幂等**。重组必须同时还原两样东西：

- **分组**——来自词级标记（段级标记做不到，见上）；
- **坐标**——来自 `raw_start` / `raw_end`，pass 3 正是为被移动的词持久化了它们。否则 pass 1
  会拿已折叠的坐标再去和 zone 几何比对。

不重组直接重跑是不成立的：`adjust_words` 逐段运行，第二遍的「段」变成 piece，胶合 run 的边界
随之改变（正是上文那个改掉 17/25297 个边界代价的机制）。

**已知例外（不修，记账）**：当一个源段同时参与「吞掉接缝的跨段 piece」和另一个 piece 时，
重组只能让它继承其中一个 piece 的标量，第二遍算出的 `confidence` 与第一遍差在末位（实测全床
**1/2347**，0.667 → 0.658；两者都远离 0.3 闸门，无下游影响，第二遍起即达不动点）。修它需要把
源段标量持久化到词级，对一个「规则选择本身影响 ≤1 条」的取证字段而言是过度工程。生产里
`round_floats` 在 split 之后按 3 位取整，这个差在真实产物中不出现。
