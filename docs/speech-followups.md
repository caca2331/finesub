## 二、各批「不要做什么」（摘要，展开在真相源里）

动手前先读对应那条——每一条都是量过之后关掉的，不是没想到：

- **P10 分离器分块权重改三角权重**——已撤回，`demix.py` 早就是 Hamming 窗 + counter 归一。
- **不把 Silero 提升为基础检测器**——外部横向证据只有一个 60 s 片段。
- **不抄 legacy env 别名机制**——不刻意兼容的规则限于 1.0.0 前的开发中版本。
- **不拿外部 DER 数字当目标**——素材难度分布不同，我们的说话人线不用 DER。
- **不往 CT2 加 CUDA graph capture**——KV cache 每步增长，要先做 shape-stable 重写（上千行
  C++），且它攻击的是组批已经在攻击的那个瓶颈。
- **分离器 FP8 / 手写 GEMM / 真 batch / 换 checkpoint / TensorRT / 16 kHz 分离**——
  [`separator-optimization.md`](separator-optimization.md) 的 E12/E14/E16 各自给了上限或硬否决。
- **三条已核实关闭的疑虑**——dry-run 与 `--execute` 复用同一段代码、`cli/_vendor` 不被 git
  跟踪、以及第三条，见真相源那张表。
