# 知识库样板（examples/knowledge）

主仓库追踪的**迷你知识库骨架**，用于说明条目格式与 index 约定；**不是**运行时默认读取的 `knowledge/`。

生产知识库仍在仓库根的 `knowledge/`（主 git 忽略，目录内嵌独立 git，见 `docs/knowledge.md`）。

## 内容

| 路径 | 说明 |
| --- | --- |
| `common/原神.md` + `common/index.md` | 题材/作品类样板 |
| `streamer/四月一日べレト.md` + `streamer/index.md` | 主播类样板 |
| `translation/common-mistake.md` | 错误台账空骨架 |
| `translation/good-example.md` | 范例库空骨架 |

本地试用可复制到 `knowledge/` 后按文档跑 harness；样板正文含第三方作品/人设专名，仅作格式参考。
